# cpu-alu-design-
# Simple 8-bit CPU with ALU

## Description
This project implements a simple 8-bit CPU with an Arithmetic Logic Unit (ALU) using Verilog HDL.

## Features
- 8-bit data processing
- Arithmetic operations
- Logical operations
- Addition and subtraction
- AND, OR, XOR operations
- Zero flag
- Verilog testbench
- Simulation support

## ALU Operations

| Opcode | Operation |
|--------|-----------|
| 000    | ADD       |
| 001    | SUB       |
| 010    | AND       |
| 011    | OR        |
| 100    | XOR       |

## Tools Used
- Verilog HDL
- Icarus Verilog
- GTKWave

## Simulation
The testbench verifies all ALU operations and displays the results during simulation.
